# Self-hosted fonts

Montserrat (content, headings, and CTAs, 400–700) and Inter (navigation, UI, and fallbacks, 400–700), Latin variable WOFF2 subsets. Downloaded from Google's official Fonts CSS API on 23 October 2026, with each family's SIL Open Font License from the google/fonts repository. Both license files are retained here.

Sources:
- https://fonts.googleapis.com/css2?family=Inter:wght@400..700&family=Montserrat:wght@500..700&display=swap
- https://github.com/google/fonts/tree/main/ofl/inter
- https://github.com/google/fonts/tree/main/ofl/montserrat

Combined file size: 83,940 bytes. Loaded once through next/font/local with swap and metric-adjusted fallback. Builds and visitors do not need to contact Google Fonts. CSS uses --font-heading and --font-body.

Font metadata inspection confirmed the Montserrat file contains the full variable wght axis from 100 to 900; 400, 500, and 600 are native weights, not simulated.
